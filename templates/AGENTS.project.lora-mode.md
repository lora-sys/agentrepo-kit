# 项目 AGENTS.md 维护模板

此文件供项目维护者填写。不要在初始化时把整份骨架复制到目标仓库。

## 选择规则

按顺序判断，命中即停。

1. 可机械验证：写入 Lint 或 CI，AGENTS 只留相关门禁名称。
2. 可由代码、配置或 README 推出：不重复记录。
3. 与本仓库无关：移到全局指令或通用 Skill。
4. 超过五步的 Agent 流程：移到 `.agents/skills/<name>/SKILL.md`，此处只留路径。
5. 仅本仓库成立且违反代价高：记录在项目 AGENTS。

保持在 150 行以内。删掉没有实际内容的章节。命令写明仓库根目录、前置条件和可验证的返回结果。不要写密钥、内网地址和个人链接。

## 可选正文骨架

```md
# <项目名>

## 优先级

本仓库明确禁令优先于通用 Skill 的默认交付流程。

- PR：<项目明确规定的例外；没有则删掉>
- 检查：<唯一可执行入口；说明全量检查由谁负责>
- 临时产物：<允许路径；禁止路径及后果>

## 项目

<只写无法从 README 或配置推导的业务事实>

## 致命陷阱

- <错误操作>：会 <具体后果>。改为 <正确动作>。

## 覆盖面

- 入口：<同一行为可从哪些入口触发>
- 端：<受影响的客户端与接口>
- 契约：<共享类型或协议的权威位置>
- 反向状态：<创建与删除、进入与退出是否配对>
- 文档：<受影响的用户文档>

## 命令与真实环境

- 工作目录：<路径>
- 安装：`<实测命令>`；前置条件 <条件>
- 测试：`<实测命令>`；通过条件 <退出码或验收值>
- 本地：`<实测命令>`；端口从 <配置路径> 读取
- 状态目录：<允许和禁止的路径及原因>

## 验证与证据

- 必须测：<本项目的高风险行为>
- 不测试：<已有其他门禁保证的类型>
- Bug 修复：<最小失败案例及修复后验收方式>

## 不变量

- <具体规则及可检查的证据>

## 交付差异

- <只写与 lora-mode 默认流程不同的项目约定>

## 文档

- `<路径>`：<本项目独有的文档要求>

## 品味

- <确实存在且会影响交付的项目偏好>

## 深流程

- <场景>：`.agents/skills/<name>/SKILL.md`
```

`lora-mode` 是可选的外部 Skill，不是 AgentRepo Kit 的运行时依赖。只有确认使用它的仓库才填写“交付差异”，不要把通用流程复制进项目 AGENTS。
